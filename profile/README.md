## MinwonQuick은

시청·구청 민원실에 가기 전에 **지금 몇 명이 기다리는지**, **얼마나 기다려야 하는지**를 알려 주는 서비스입니다.
행정안전부가 공공데이터포털로 공개하는 민원실 번호표 발권 정보를 받아, 실제 방문자 기준의 대기 현황을 보여 줍니다.

| 기능 | 설명 |
|---|---|
| 🎫 **업무별 실시간 대기** | 민원실마다 업무별(여권·등본·가족관계 등) 대기 인원과 현재 호출번호를 보여 줍니다. |
| ⏱️ **예상 대기시간** | 번호표 호출 속도로 계산한 추정치이며, 화면에 '추정'이라고 표시합니다. |
| 🕘 **기준시각 표시** | 모든 숫자에 출처와 기준시각을 함께 표시합니다. 갱신이 늦은 값은 '지연'으로 표시하고, 60분이 지나거나 날짜가 바뀐 값은 숨깁니다. |
| 📈 **혼잡 패턴** | 오늘 대기 추이(15분 단위), 시간대별·요일별 평균으로 덜 붐비는 시간을 찾을 수 있습니다. |
| 🗺️ **3D 지도·주변 민원실** | 지형과 건물이 보이는 지도에 기관별 대기 인원을 기둥으로 표시하고, 가까운 다른 민원실을 함께 보여 줍니다. |
| 🔔 **대기 알림** | 정한 인원 이하로 대기가 줄면 알림을 보냅니다. |

> 2026년 10월 기준으로 공식 실시간 데이터를 제공하는 민원실은 전국 44곳입니다. 데이터가 없는 기관은 숫자 대신 '실시간 정보 미제공'으로 표시합니다.

## 서비스 구성

| 구성 | 기술 |
|---|---|
| 웹 (PWA) | Next.js 15 · React 19 · Tailwind CSS 4 · three.js · MapLibre GL |
| 모바일 앱 | Expo 52 · React Native |
| 서버 | NestJS 10 · Prisma 5 · PostgreSQL · Server-Sent Events |

| 저장소 | 역할 |
|---|---|
| `MinwonQuick_Interface` | 백엔드 API, 실시간 데이터 수집·해석, 알림 (비공개) |
| `MinwonQuick-FE` | 웹 서비스 (비공개) |
| `MinwonQuick-App` | iOS·Android 앱 (비공개) |

## 지키는 원칙

- **정확성** — 출처와 기준시각 없이 숫자를 보여 주지 않습니다. 추정치는 추정이라고 표시합니다.
- **접근성** — 한국형 웹 콘텐츠 접근성 지침(KWCAG 2.2)에 맞춰 명도 대비, 키보드 이용, 본문 바로가기, 움직임 줄이기를 지원합니다.
- **개인정보 최소화** — 위치는 저장하지 않고, 공개 후기의 작성자 이름은 가려서 보여 줍니다.
